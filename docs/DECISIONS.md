# 决策记录 — dsh-capability-hub（能力中心）

本文记录设计决策；代码注释中的 `D-xx` 编号指向这里。
决策编号是稳定标识（A 形态与边界、B 技能、C MCP 管理、D MCP 运行时（0.7.0 改用官方插件，见 ADR-0010；0.6.0 前叫「懒加载运行时」）、E 运行态面板、F 工程与交付），
引用时直接写编号即可，不要重新编号。标版本号（如「0.3.0」「0.7.0」）的内容是该版本的修订或新增；界面细节见 [UI-DESIGN.md](UI-DESIGN.md) 第 3 节。
