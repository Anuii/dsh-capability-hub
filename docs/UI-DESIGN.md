# 界面设计规范（UI-DESIGN）

能力中心界面的设计原则与各页面规格。改界面前先读本文；组件 API 见 [CLIENT-GUIDE.md](CLIENT-GUIDE.md) 第 10 节（kit），宿主组件与主题变量见 [PRIMITIVES.md](PRIMITIVES.md)。

## 0. 原则（取舍时以此为准）
1. **安静**：层级靠字号、字重、灰度，不靠颜色；默认画面几乎全是中性灰。
2. **一处一事**：每一行只回答「这是什么、开没开」，其余信息进详情。
3. **只在需要时出现**：状态标记、横幅、悬停操作只在有事时出现；一切正常时画面上没有它们。
4. **一个强调色**：DSH 主题强调色只用于主按钮、「可更新」、活跃状态点；红色只表示错误，琥珀色只表示冷却或警告；不用绿色。
5. **不删功能**：DECISIONS 中的能力全部保留，只是换位置。

## 1. 视觉语言（全部映射到 DSH 主题变量，禁止写死颜色）
- 间距 4 / 8 / 12 / 16 / 24；圆角：容器 10px，控件 6px。
- 字号：页面标题 18/600；分组标签 12/500 次要色；行标题 14/500；行副标题 12.5/400、单行截断，颜色比次要色再弱一级但须满足 WCAG AA（4.5:1）；路径与命令用 DSH 代码字体（`--ds-font-family-code`），12px。
- 列表：一个圆角面板，行与行之间 1px 细分隔线，不给每行套卡片。
- 行：最小高度 52px，内容垂直居中；悬停背景提亮一级、行尾出现淡色「›」；整行可点击打开详情，Tab 聚焦、Enter 打开。未悬停时每行最多一个可见控件（开关）。
- 状态点：灰 = 空闲，强调色 = 活跃，红 = 失败，琥珀 = 冷却（只用于 MCP）。
- 标记：小号描边胶囊 11/500，tone 为 neutral / accent / warn / danger，每行最多 2 个。
- 详情抽屉：右侧滑出，宽 560px（宽内容 720–920px，窄屏 100%），Esc 与遮罩可关闭，关闭后焦点回到原行；头部为标题、单行截断的副标题与开关；底部只在有操作时出现，危险操作放最左，用弱化的红色文字按钮。
- 开关：在能力中心作用域内缩到宿主尺寸的约 80%，颜色保持 DSH 原生。
- 加载用 6 行骨架屏；空状态 = 一句标题 + 一句说明 + 一个按钮。
- 不放常驻的解释性长句；必要说明进工具提示或详情。

## 2. 外壳
- 页头：「能力中心」+ 右上角「ⓘ」（诊断信息模态框）；下方是下划线式标签。
- 页面上不放诊断卡片；模块降级或 mcp 工具退回桩时，页头下方出现 warn 横幅「部分功能不可用：<模块>」+「查看详情」。
- 标签切换保留各自的搜索、筛选、滚动位置（标签隐藏而不卸载）。

## 3. 当前版本（0.2.0）
- **技能**：工具栏 = 搜索、筛选（全部 / 已启用 / 已停用 / 需关注）、主按钮「添加技能」、「⋯」（检查全部更新、为无来源技能推测来源、回收站、GitHub 凭据与配额）。列表按技能目录分组（家目录路径缩写为 `~\…`，DSH 内置根显示为「DSH 内置」并标只读，空目录隐藏、底部一行可切换显示）。行 = 名称 + 描述 + 标记（不可加载 / 可更新 / 被遮蔽）+ 开关。详情抽屉：概览 → 体检 → 来源与更新 → 文件 → SKILL.md（默认折叠）；底部删除（区分「目录」与「文件」）。另有添加技能抽屉与回收站抽屉。
- **MCP 服务器**：工具栏 = 搜索、筛选（全部 / 已启用 / 已停用 / 有错误）、「添加服务器 ▾」（手动填写、粘贴 JSON、预设模板、从 Claude Code / Codex 导入）、「⋯」（全局设置）。行 = 状态点 + 名称 + 等宽摘要「命令 参数 · n 个工具」+ 标记（连接失败 / 冷却中）+ 开关，悬停出现拖动把手。详情抽屉：概览 → 工具（名称列表与刷新）→ 环境变量与请求头（遮罩、显示）→ 最近失败；底部删除｜JSON 编辑、编辑。
- **运行态**：工具栏 =「只看当前会话」+ 自动刷新与刷新按钮；服务器分组（缓存、失败、冷却，悬停刷新缓存、断开全部）；会话分组（子代理缩进，实例行悬停断开）。

## 4. 下一版本（0.3.0，已与用户敲定，待实现）
对应 DECISIONS 中修订后的 D-A2、D-B6、D-E1 与新增的 D-B14～D-B16；术语见 [GLOSSARY.md](../GLOSSARY.md)。
- **标签减为两个：技能 / MCP**。插件管理页「配置」入口仍直达 MCP。
- **技能列表的两级折叠**：
  - 一级 = 层级：**DSH 内置**（默认折叠）、**用户级**、**项目级**，均可折叠；自定义技能目录归用户级；没有当前工作区时项目级只显示一行说明。
  - 二级 = 来源仓库：层级内按 `owner/name` 分组，可折叠，「无来源」排最后；DSH 内置不再细分。
  - 每行带一个淡色「目录」标签（如 `.agents`、`.dsh`）；工具栏增加「目录」筛选。只显示 DSH 会加载的技能目录，不显示 `~/.claude/skills`。
  - 遮蔽、需关注、启停、详情、回收站行为不变。
- **「添加技能」= 仓库视图**（宽抽屉或独立视图）：
  - 顶部：粘贴仓库地址可直接浏览或加入仓库列表；skills.sh 搜索结果可一键加入仓库列表。
  - 仓库列表：增删，每个仓库可设分支与子目录；预置仓库也在其中。
  - 汇总发现：所有仓库的技能，可按「已安装 / 未安装」与仓库筛选，勾选 → 选安装位置 → 安装。
  - 扫描：显示上次结果与扫描时间，点「刷新」才联网；第一次没有缓存时自动扫一次；增删仓库只补扫该仓库。
- **MCP 页底部「运行中」区域**：按会话分组的实例（子代理缩进、「只看当前会话」），可折叠，没有活跃实例时自动收起；刷新缓存、断开全部移入服务器详情抽屉；服务器行的状态点、失败与冷却标记保持不变。

## 5. 界面验收口径
- 未悬停时每行可见控件不超过 1 个（开关）。
- 截图中除强调色、红、琥珀外没有其他彩色元素；正常数据下技能页首屏没有红色或琥珀色。
- 首屏常驻元素自上而下只有：页头、标签、工具栏、列表。
- 以前所有功能流程都能完成；亮色、暗色各有截图；tsc 0 错，全部单测通过。
