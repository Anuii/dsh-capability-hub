# 界面设计规范（UI-DESIGN）

能力中心界面的设计原则与各页面规格。改界面前先读本文；组件 API 见 [CLIENT-GUIDE.md](CLIENT-GUIDE.md) 第 10 节（kit），宿主组件与主题变量见 [PRIMITIVES.md](PRIMITIVES.md)。

## 0. 原则（取舍时以此为准）
1. **安静**：层级靠字号、字重、灰度，不靠颜色；默认画面几乎全是中性灰。
2. **一处一事**：每一行只回答「这是什么、开没开」，其余信息进详情。
3. **只在需要时出现**：状态标记、横幅、悬停操作只在有事时出现；一切正常时画面上没有它们。
4. **一个强调色**：DSH 主题强调色只用于主按钮、「可更新」、活跃状态点；红色只表示错误，琥珀色只表示连接中或警告；不用绿色。
5. **不随手删功能**：界面改版时 DECISIONS 中的能力保留，只是换位置；要删功能先改 DECISIONS（0.7.0 按使用者的决定删了 MCP 的表单、预设、导入、「运行中」与全局设置页）。

## 1. 视觉语言（全部映射到 DSH 主题变量，禁止写死颜色）
- 间距 4 / 8 / 12 / 16 / 24；圆角：容器 10px，控件 6px。
- 字号：页面标题 18/600；分组标签 12/500 次要色；行标题 14/500；行副标题 12.5/400、单行截断，颜色比次要色再弱一级但须满足 WCAG AA（4.5:1）；路径与命令用 DSH 代码字体（`--ds-font-family-code`），12px。
- 列表：一个圆角面板，行与行之间 1px 细分隔线，不给每行套卡片。
- 行：最小高度 52px，内容垂直居中；悬停背景提亮一级、行尾出现淡色「›」；整行可点击打开详情，Tab 聚焦、Enter 打开。未悬停时每行最多一个可见控件（开关）。
- 状态点：灰 = 空闲，强调色 = 活跃，红 = 失败，琥珀 = 连接中（只用于 MCP）。
- 标记：小号描边胶囊 11/500，tone 为 neutral / accent / warn / danger，每行最多 2 个。
- 详情抽屉：右侧滑出，宽 560px（宽内容 720–920px，窄屏 100%），Esc 与遮罩可关闭，关闭后焦点回到原行；头部为标题、单行截断的副标题与开关；底部只在有操作时出现，危险操作放最左，用弱化的红色文字按钮。
- 开关：在能力中心作用域内缩到宿主尺寸的约 80%，颜色保持 DSH 原生。
- 加载用 6 行骨架屏；空状态 = 一句标题 + 一句说明 + 一个按钮。
- 不放常驻的解释性长句；必要说明进工具提示或详情。
- 重复出现在每一行的信息要么不显示、要么调淡：只在有区别时才显示（例如目录标签），常见的默认值用最弱的说明色、例外用正常次要色（例如调用权限）。
- 输入框占位文字用次要色（宿主默认太淡）；数量为 0 的「需关注 / 有错误」分段调淡，有问题时恢复正常。
- 页头与正文最大宽度 1180px（左对齐），宽屏时描述不被拉得过长。

## 2. 外壳
- 页头：「能力中心」+ 右上角「ⓘ」（诊断信息模态框）；下方是下划线式标签。有服务器处于错误状态时「MCP」标签文字旁出现红点（悬停说明）。
- 页面上不放诊断卡片；模块降级或 MCP 运行时退回桩时，页头下方出现 warn 横幅「部分功能不可用：<模块>」+「查看详情」。
- 插件升级后没重启 DSH（浏览器半已是新版本、宿主半还是旧的）时，页头下方出现 warn 横幅「能力中心已升级到 x，但 DSH 还在运行 y 的宿主代码；重启 DSH 后新功能才能用」；新接口 404 时的报错也给同样的提示。
- 标签切换保留各自的搜索、筛选、滚动位置（标签隐藏而不卸载）。

## 3. 当前版本（0.7.0；MCP 页只用 JSON 配置、去掉「运行中」区域与全局设置页，行状态与抽屉重做，其余与 0.3.4 相同）
页面只有两个标签：**技能 / MCP**（D-A2）。插件管理页本插件那一行的「配置」直达 MCP。

- **技能**：工具栏 = 搜索、筛选（全部 / 模型可调用 / 模型不可调用 / 需关注）、主按钮「添加技能」、「⋯」（检查全部更新、回收站）。没有目录下拉（使用者决定）：目录标签照旧只在行上出现。
  - 列表两级折叠（D-B14）：一级 = 层级 **DSH 内置**（默认折叠，标「只读」）/ **用户级** / **项目级**，标题行显示技能数；自定义技能目录归用户级，位于 DSH 安装目录（app.asar）里的归 DSH 内置；没有当前工作区时项目级只有一行说明。二级 = 来源仓库 `owner/name`（名称排序，「无来源」最后）；DSH 内置不细分；某层级全是无来源、或来源数据不可用时直接列技能。折叠头是整条按钮（Tab 聚焦、Enter / Space 切换）。
  - 行 = 名称 + 淡色「目录」标签（技能目录路径里 skills 前一段，如 `.agents`；等宽小字、无边框、不算标记，悬停给完整路径；只在该层级的技能来自不止一个目录时显示）+ 描述 + 标记（不可加载 / 可更新 / 被遮蔽）+ 调用权限文字 + 开关。调用权限（D-B17）是开关左侧一小段文字，固定宽度右对齐成一列：「模型、用户 / 仅模型 / 仅用户 / 不可调用」，默认的「模型、用户」用最弱的说明色、例外用次要色；悬停说明两种调用各自的来源；开关管的是模型调用，用户调用只读。只读技能（DSH 内置、只读的自定义目录）不显示开关（禁用的开关会被看成「已关闭」），留同宽空位让文字仍对齐。
  - 筛选口径：后两段筛的就是行右侧开关管的那件事（`disable-model-invocation`，D-B3 / D-B17），所以叫「模型可调用 / 模型不可调用」，开关的悬停与启停 Toast 用同一套说法；「需关注」= 不可加载 + 被遮蔽 + 可更新。搜索或任何筛选生效时有匹配的分组自动展开、无匹配的隐藏；筛选中仍可手动折叠（只对这一次筛选有效，换一种筛选又全部展开），清空后回到原来的折叠状态。
  - 详情抽屉：概览 → 体检 → 来源与更新 → 文件 → SKILL.md（默认折叠）；底部删除（区分「目录」与「文件」）。另有回收站抽屉。
- **添加技能 = 仓库视图**（D-B16，宽抽屉 860px），自上而下：
  - 一个输入框（D-B16，0.3.4）：内容像仓库地址（owner/name、GitHub 链接，可带 /tree/<分支>/<子目录>）时，右侧出现分支输入与「浏览」（临时只看这一个仓库，可直接装）「加入仓库列表」；否则是「搜索 skills.sh」，Enter 同样生效。搜索结果先是一行「搜到 n 个结果 · 收起 / 展开」，下面约 4 行高的滚动框，结果行悬停「浏览」「加入仓库列表」，已在列表的标「已在列表」；从结果里浏览或加入后自动收起。临时浏览的结果与安装反馈出现在输入框正下方并自动滚到可见，「返回汇总」回来。
  - 仓库列表（默认折叠成一行「仓库列表 · n 个」）：行 = 仓库名（预置的标「预置」）+「分支 · 子目录 · n 个技能 / 扫描失败：原因 / 未扫描」；悬停浏览 / 编辑 / 移除，编辑就地展开分支与子目录。
  - 汇总发现：工具栏 = 搜索、全部 / 未安装 / 已安装（带数）、仓库下拉、「上次扫描：x 分钟前」与「刷新」。按仓库分组折叠（0.3.4）：分组标题 = 仓库名 + 等宽「@分支」+ 技能数，技能数超过 50 的仓库默认折叠；搜索或筛选时有匹配的分组先全部展开、仍可手动折叠。行 = 勾选框（唯一可见控件）+ 名称 + 描述 + 「已安装」。结果缓存在插件数据目录，打开先显示缓存；第一次没有缓存时自动扫一次，之后只有「刷新」才联网；加入、修改仓库只补扫该仓库，移除仓库同时删掉它的结果；每组每批渲染 200 行，组下「再显示」。
  - 底部（有勾选时才出现）：安装位置（`~/.agents/skills` 默认、`~/.dsh/skills`、当前项目）+ 已选数 +「安装选中技能」；跨仓库的勾选按仓库分组依次安装，结果逐项列在下方。
- **MCP**（0.7.0）：工具栏 = 搜索、筛选（全部 / 已启用 / 已停用 / 有错误）、「添加服务器」（粘贴 JSON 添加）；每台服务器只用 JSON 编辑（D-C2 / D-C3），表单、预设模板、从 Claude Code / Codex 导入都已删除，「⋯」里的全局设置页也删除。行 = 状态点 + 名称 + 等宽摘要「程序名 参数」（路径只留文件名，如 `node fake-mcp-server.mjs`；完整命令在悬停提示与详情里）+ 连接状态文字「已连接 · N 个工具 / 未连接」（「按会话」的服务器显示「按会话 · 当前 N 个会话已连接」）+ 标记（连接失败）+ 开关，悬停出现拖动把手。
  - 详情抽屉：概览 → 工具（连接状态与工具名列表、「重新连接」：卸下再挂上）→ 环境变量与请求头（遮罩、显示）；底部删除｜JSON 编辑。
  - 页面底部不再有「运行中」区域（D-E1，0.7.0 删除）：连接状态见每行的「已连接 · N 个工具 / 未连接」与抽屉里的「重新连接」。

## 4. 下一版本

## 5. 界面验收口径
- 未悬停时每行可见控件不超过 1 个（开关）。
- 截图中除强调色、红、琥珀外没有其他彩色元素；正常数据下技能页首屏没有红色或琥珀色。
- 首屏常驻元素自上而下只有：页头、标签、工具栏、列表。
- 以前所有功能流程都能完成；亮色、暗色各有截图；tsc 0 错，全部单测通过。
