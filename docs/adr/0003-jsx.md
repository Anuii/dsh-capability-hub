# ADR-0003：界面代码用 JSX

日期：2026-10-05 · 状态：已采纳

## 背景
0.3.x 的界面全部手写 `React.createElement(...)` 嵌套（784 处）。仓库视图这类文件一层套一层，读结构要数括号；属性名还得写成字符串（`"data-testid": ...`）。

## 决定
- `.tsx` 文件一律用 JSX。构建仍由 esbuild 完成（`jsx: "transform"`、`jsxFactory: React.createElement`），tsconfig 用同样的经典 JSX 设置：不引入 `react/jsx-runtime`，产物里 React 仍来自宿主的 `__ModuleLoader__`。
- 排版交给 prettier（`.prettierrc.json`，宽度 120）。
- 转换用一次性的 codemod（按语法树把 createElement 改写成等价 JSX），再用 prettier 排版；转换前后 15 张亮 / 暗截图逐像素对比，只有时间戳不同。

## 后果
- 界面结构一眼可读；属性名与 DOM 一致。
- 少数检查源码文本的单测改成匹配 JSX 写法；这类测试会在「逻辑进可测模块」那一步继续减少。
